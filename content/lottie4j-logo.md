The Lottie4J logo has been designed as a vector graphic to be able to create a Lottie animation out of it (of course... 😉). The logo is available in different formats in the [lottie4j-logo repository on GitHub](https://github.com/lottie4j/lottie4j-logo). 

In this video you see the same Lottie json animation being played with the JavaFX viewer on the left, and the JavaScript web player on the right. They look identical, which is the goal of the Lottie4J project, to reach the same state as the web and other Lottie players.
